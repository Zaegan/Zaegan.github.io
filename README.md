# zaegan.github.io

Privacy policies for Zaegan's apps, served at `https://zaegan.github.io/<App>/privacy.html`. The apps link to these
addresses, so a folder must keep its name.

- `BurnerPad/privacy.html`
- `InfiniteCalc/privacy.html`

The site is rebuilt only when this repository changes, so policy updates (one app or several at once) cost one small
GitHub Pages build each, and pushes to the apps' own repositories cost nothing.
